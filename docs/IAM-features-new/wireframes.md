## 10. Design System

### Colors
- **Primary:** #3B82F6 (Blue 500)
- **Success:** #10B981 (Green 500)
- **Warning:** #F59E0B (Amber 500)
- **Danger:** #EF4444 (Red 500)
- **Background:** #F9FAFB (Gray 50)

### Role Badges
- **Administrator:** Red/Pink
- **Admin Lembaga:** Purple
- **Project Manager:** Blue
- **Relawan:** Green

### Components (shadcn-vue)
- Button, Card, Table, Dialog
- Select, Input, Badge, Avatar
- Dropdown Menu, Toast, Skeleton
- Pagination
